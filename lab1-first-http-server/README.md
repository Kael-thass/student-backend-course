##Контрольные вопросы
1. Что такое клиент-серверная архитектура?
Это модель взаимодействия, где клиент (браузер) отправляет HTTP-запрос, а сервер (бэкенд-приложение) принимает его, обрабатывает и отправляет HTTP-ответ. Бэкенд работает на сервере и не виден пользователю напрямую.
2. Какой протокол используется для общения клиента и сервера в вебе?
HTTP — это основной протокол передачи данных в интернете. В данной работе используется метод GET для запроса данных.
3. Что такое эндпоинт (endpoint)?
Это конкретный адрес (URL) вместе с методом HTTP, по которому клиент обращается к серверу для получения ресурса. Например: GET /api/users.
4. Какую структуру имеет HTTP-запрос и HTTP-ответ? Что такое код состояния (status code)?
HTTP-запрос содержит метод, URL и заголовки, а HTTP-ответ — статус, заголовки и тело. Код состояния (например, 404) показывает результат обработки запроса сервером.
5. Что такое JSON? Почему он популярен в веб-разработке?
JSON (JavaScript Object Notation) — текстовый формат обмена данными. Он стал стандартом де-факто для REST API благодаря простоте и читаемости.
6. Как запустить сервер на Node.js или Flask?
Для Node.js: npm run dev (с nodemon) или node app.js. Для Flask: python app.py.
7. Что такое автоматический перезапуск сервера и зачем он нужен? Какой пакет используется для Node.js?
Это функция, которая перезапускает сервер при изменении кода, чтобы не делать это вручную. Для Node.js используется пакет nodemon, для Python — режим debug=True во Flask.
8. Какие коды состояния HTTP вы знаете? За что отвечает код 404?
Код 404 означает "Not Found" — маршрут не найден. Другие коды: 200 (OK), 500 (Internal Server Error).
9. Что такое middleware в Express / декораторы запросов во Flask?
Middleware в Express — это функции, выполняемые до обработки запроса (например, логирование). Во Flask аналогичную роль играют декораторы, такие как @app.before_request.
10. Как получить параметр из URL-пути (например, ID пользователя) в вашем фреймворке?
В Express: req.params.id в маршруте /api/users/:id. Во Flask: параметр передаётся в функцию-обработчик, например def get_user(user_id).
